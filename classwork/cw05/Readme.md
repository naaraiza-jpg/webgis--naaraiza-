# Phoenix Shade Finder

## Project Overview

Phoenix Shade Finder is an interactive web mapping application designed to help users explore cooling resources and transportation information in the Phoenix area. The project focuses on making information about cooling centers, hydration stations, rail stations, and nearby cities easier to access through a map.

The application was created using HTML, CSS, JavaScript, and Leaflet. It uses GeoJSON data to display different locations and geographic information.

## Features

- **Interactive Map:** Displays the Phoenix area using OpenStreetMap and USGS Topographic basemaps.
- **Cooling Centers:** Shows cooling center locations with popups containing additional information.
- **Hydration Stations:** Displays hydration stations using custom water icons and clustered markers.
- **Rail Stations:** Shows rail station locations with tooltips containing station information.
- **City Population Data:** Includes a population-based choropleth map that uses different colors to represent population ranges.
- **Layer Controls:** Allows users to turn map layers on and off using checkboxes.
- **Locate Me:** Allows users to view their current location on the map, when location access is available.
- **Site Selection:** Allows users to click locations to view information and highlight selected sites.
- **Map Count:** Displays the number of cooling centers, hydration stations, and rail stations currently visible on the map.

## Purpose

The purpose of Phoenix Shade Finder is to make it easier to explore cooling resources and transportation information in the Phoenix area. By combining these locations into an interactive map, users can better understand where resources are located and how they relate to the surrounding urban environment.

This project also demonstrates how web mapping tools and geographic data can support urban planning, public services, and community resource accessibility.
