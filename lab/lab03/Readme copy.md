# Cool Corridors - Lab 02 
### Naji Araiza

## What I built
I created a Home page for Cool Corridors with information about shaded walking routes, a walking schedule, and a volunteer signup form. I also created an interactive map with checkboxes for shaded routes, cooling centers, and bus stops.

## Phone test
I tested the Home page and Map page at a phone viewport of 390 × 844 pixels. Both pages fit the viewport width without horizontal page scrolling. The route cards stack vertically on the Home page, and the map layers are available above the map on the Map page.

## Screen reader test
I ran a Lighthouse accessibility audit on the Home page and received a score of 100. The audit did not identify accessibility issues that required fixes.

## Mark's doc
I followed the assignment requirements for the page content, navigation, map, mobile layout, and accessibility testing. I used descriptive image text, labels for form fields, and visible keyboard focus styling.
